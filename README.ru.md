# tdex — Terminal Tools

[English](README.md) | **Русский**

Интерактивный TUI-каталог консольных приложений и системных CLI-утилит для Linux.
Показывает, что установлено (●) и чего нет (○), запускает программы с передачей им
терминала и возвращает вас в каталог после выхода. Для отсутствующих программ
показывает команды установки для Arch, Debian/Ubuntu и Fedora — **сам ничего не устанавливает**.

```
┌──────────────────────────────────────────────────────────────┐
│                        TERMINAL TOOLS                   tdex │
│                        [ USER MODE ]            Tab → SYSTEM │
├─ Категории ─────────────────────┬─── установлено 14 из 81 ───┤
│ > Мониторинг               2/5  │ Мониторинг                 │
│   Информация о системе     1/4  │ Доступно: 2 из 5           │
│   Файловые менеджеры       1/5  │ ● btop    Интерактивный …  │
│   ...                           │ ○ atop    Мониторинг …     │
├─────────────────────────────────┴──────────────── Arch Linux ┤
│  ↑↓  Навигация   Enter  Выбрать   Tab  Режим   /  Поиск  ... │
└──────────────────────────────────────────────────────────────┘
```

## Требования

- Linux, Python 3.10+ (только стандартная библиотека: `curses`, `json`, `subprocess`, `shutil`)
- терминал с поддержкой UTF-8, минимальный размер 44×14

## Установка

Рекомендуемый способ установки — через [pipx](https://pipx.pypa.io/):

```sh
git clone https://github.com/Axawys/tdex.git && cd tdex && pipx install .
```

Команда `tdex` будет установлена в `~/.local/bin`, после этого достаточно запустить `tdex`.
Обновление: `git pull && pipx install --force .` (в каталоге `tdex`).

Запуск без установки, из склонированного каталога:

```sh
python3 -m tdex          # из каталога проекта
./tdex.sh                # то же самое, из любого места; рабочий каталог не меняется
```

Параметры командной строки:

| Параметр | Назначение |
|---|---|
| `-m user\|system` | начальный режим |
| `-c FILE` | использовать другой JSON-каталог (можно указать несколько раз) |
| `--no-user-catalog` | не подключать `~/.config/tdex/catalog.d/*.json` |
| `-l`, `--list` | вывести каталог со статусами установки без TUI |
| `--check` | проверить корректность файлов каталога |

## Клавиши

| Клавиша | Действие |
|---|---|
| `↑` `↓` / `j` `k`, `PgUp` `PgDn`, `Home` `End` | перемещение по списку |
| `Enter` / `→` | открыть категорию / запустить программу |
| `Esc` / `←` / `Backspace` | назад |
| `Tab` | переключить USER ↔ SYSTEM (у каждого режима своя позиция) |
| `i` | подробная информация о программе |
| `a` | запустить с вводом аргументов |
| `m` | открыть man-страницу |
| `/` | поиск по текущему режиму |
| `r` | заново проверить, что установлено |
| `?` / `F1` | справка |
| `q` / `Ctrl+C` | выход |

В поиске буквы попадают в запрос; `↓` или `Enter` переводят фокус на результаты,
где работают `Enter`, `i`, `a`, `m`; `/` возвращает к редактированию запроса.
`Tab` в поиске переносит тот же запрос в другой режим.

## Как запускаются программы

- Наличие программы проверяется через `$PATH` (`shutil.which` — аналог `command -v`)
  при старте, после каждого запуска, по `r` и **ещё раз непосредственно перед запуском**.
- Запуск идёт через `subprocess.Popen([...])` без оболочки: аргументы передаются
  списком, строки не склеиваются. `sudo` нигде не вызывается.
- На время работы программы curses приостанавливается (`endwin`), Ctrl+C и Ctrl+\
  получает запущенная программа, а не каталог. После выхода восстанавливаются
  настройки терминала, учитывается изменившийся размер окна, и интерфейс перерисовывается.
- Утилиты, которые печатают результат и сразу завершаются (`ls`, `fastfetch`, …),
  помечены `"pause": true` — после них tdex ждёт Enter, чтобы вывод можно было прочитать.
- Для утилит с `"prompt_args": true` (по умолчанию — все из SYSTEM) Enter открывает поле
  аргументов с подставленными значениями по умолчанию. Кавычки разбираются как в shell
  (`shlex`), `~` в начале аргумента раскрывается, но `*`, `|`, `>`, `$VAR` — нет.
- Встроенные команды оболочки (`cd`, `export`, `jobs`, …) нельзя запустить отдельным
  процессом, поэтому для них Enter показывает `help <команда>` из bash.

## Каталог программ

Каталог лежит в [`tdex/data/catalog.json`](tdex/data/catalog.json) и полностью отделён от
интерфейса: категории и их порядок берутся из файла. Чтобы добавить программу, не трогая
встроенный каталог, положите JSON-файл в `~/.config/tdex/catalog.d/` — записи с тем же
`mode` + `name` заменяют встроенные.

```json
{
  "tools": [
    {
      "name": "btop",
      "command": "btop",
      "mode": "user",
      "category": "Мониторинг",
      "description": "Интерактивный мониторинг процессов и ресурсов системы",
      "tags": ["monitor", "process", "cpu"],
      "install": {
        "arch": "sudo pacman -S btop",
        "debian": "sudo apt install btop",
        "fedora": "sudo dnf install btop"
      }
    }
  ]
}
```

Обязательные поля: `name`, `command`, `mode` (`user` / `system`), `category`,
`description`, `install`. Необязательные:

| Поле | Назначение |
|---|---|
| `aliases` | альтернативные имена исполняемого файла (`bat` → `batcat` в Debian) |
| `args` | аргументы по умолчанию (список строк) |
| `tags` | ключевые слова для поиска (например, английские: `monitor`, `editor`) |
| `pause` | ждать Enter после завершения (по умолчанию `true` для SYSTEM) |
| `prompt_args` | спрашивать аргументы перед запуском (по умолчанию `true` для SYSTEM) |
| `builtin` | встроенная команда оболочки |
| `notes`, `url` | дополнительная информация в окне `i` |

Ключи в `install` произвольные; известные подписи: `arch`, `aur`, `debian`, `fedora`,
`cargo`, `go`, `pip`, `snap`, `flatpak`, `nix`, `other`. Строка для вашего дистрибутива
(по `/etc/os-release`) подсвечивается. Команды установки указаны ориентировочно —
имена пакетов в разных версиях дистрибутивов могут отличаться.

`python3 -m tdex --check` проверяет файлы и сообщает об ошибках с номером записи.

## Структура

```
tdex/
  catalog.py      загрузка, проверка и поиск по каталогу
  system.py       поиск исполняемых файлов, статусы, определение дистрибутива
  launcher.py     запуск программ с передачей терминала и возвратом в TUI
  data/catalog.json
  ui/
    app.py        главный цикл, стек экранов, действия
    screens.py    экраны: категории, список утилит, поиск
    dialogs.py    окна: информация, «не установлено», аргументы, справка
    details.py    текстовые блоки с описанием утилит и категорий
    widgets.py    рамки, списки с прокруткой, поле ввода
    text.py       ширина строк в ячейках терминала, перенос
    theme.py      цвета (учитывается NO_COLOR)
    keys.py       чтение клавиш
tests/            unit-тесты: python3 -m unittest discover -s tests -t .
```
